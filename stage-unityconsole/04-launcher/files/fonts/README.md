# UnityConsole 同梱フォント

ランチャー（`ucon-launcher.py`）の表示に使うピクセルフォント。
イメージでは `/usr/share/fonts/truetype/00ff/` に置かれる。

- 作者: hicc（患者長ひっく）
- 配布: ゼロピクセルフリーフォント（x0y0pxFreeFont） https://hicchicc.github.io/00ff/ ／ https://github.com/hicchicc
- 取得: 2026-09-16（GitHub `hicchicc/hicchicc.github.io` の `00ff/` から無改変で同梱）

| ファイル | 名称 | 版 | ランチャーでの用途 |
| --- | --- | --- | --- |
| `x12y16pxMaruMonica.ttf` | マルモニカ | Version 2025-09-03 | 本文（JIS第1・第2水準漢字を収録。ゲーム名など任意の文字列） |
| `x14y24pxHeadUpDaisy.ttf` | ヘッドアップデイジー | Version 2025-09-19 | 見出し（英数・かなのみ。`UNITY CONSOLE` の表示に限定） |

ドット単位で鮮明に出すため、原寸（マルモニカ 16px / ヘッドアップデイジー 24px）でアンチエイリアス無しに描画し、整数倍で拡大している。
